# ESP32-S3                                  Jetson

   │                                        │
   │──── 1. 请求 Jetson 当前时间 ──────────►│
   │◄─── 2. 返回时间，用于 ESP 校时 ────────│
   │                                        │
   │──── 3. 发送预测指令和当前时间 ─────────►│
   │                                        │
   │                       4. 根据时间查找光谱文件
   │                       5. 读取并解码 TXT/SPC
   │                       6. 加载好的模型预测浓度
   │                                        │
   │◄─── 7. 返回浓度或错误信息 ────────────│
   │                                        │
   └── 8. ESP 接收并打印结果                 │

为了减少长期运行时的时钟偏差，示例会在校时成功后，每隔约 60 秒再次向 Jetson 请求时间。
ESP 发送预测请求
ESP 校时成功后，测试代码会每隔约 10 秒读取一次 ESP 当前时间，并发给 Jetson。
例如：
{"cmd":"PREDICT","id":1,"time":"20260415181120561"}

## Jetson 分析成功时，ESP 会收到类似

 {
  "id": 1,
  "status": "ok",
  "time": "20260415181120561",
  "file": "20260415181120561_样品.txt",
  "concentration": 5.2448,
  "unit": "mmol/kg"
 }
